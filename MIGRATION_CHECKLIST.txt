═══════════════════════════════════════════════════════════════
  STEP-BY-STEP MIGRATION
═══════════════════════════════════════════════════════════════

☐ 3. Open browser and go to: https://dashboard.render.com

☐ 4. Log in if needed

☐ 5. Look for your POSTGRESQL database service
     ✓ Look for: elephant icon 🐘 or "PostgreSQL" type
     ✗ Don't click: Web Service or Frontend

☐ 6. Click on the PostgreSQL database name

☐ 7. Click the "Shell" tab at the top
     (It's usually: Info | Metrics | Logs | Shell | Settings)

☐ 8. You should see a terminal prompt like:
     postgres=#
     
     ✓ If you see this, continue
     ✗ If you don't, go back to step 5

☐ 9. Go to the Notepad window with the SQL file

☐ 10. Select ALL the text (Ctrl+A)

☐ 11. Copy it (Ctrl+C)

☐ 12. Go back to the browser with the Shell

☐ 13. Click inside the terminal area

☐ 14. Paste the SQL code (Ctrl+V)

☐ 15. Press ENTER

☐ 16. Wait 5-10 seconds for it to finish

═══════════════════════════════════════════════════════════════
  COMMON ISSUES & SOLUTIONS
═══════════════════════════════════════════════════════════════

Issue: "relation user_follows already exists"
Solution: ✅ This is FINE! It means it's already created. Continue!

Issue: "permission denied"
Solution: ❌ Contact your database admin for permissions

Issue: Can't find Shell tab
Solution: ❌ Make sure you clicked the DATABASE, not Web Service

Issue: Nothing happens after pasting
Solution: ⚠️ Press Enter key to execute the SQL

Issue: Some commands say "already exists"
Solution: ✅ This is FINE! Safe to ignore and continue
