  STEP 1: RUN DATABASE MIGRATION (EASIEST METHOD)
═══════════════════════════════════════════════════════════════════════

1. Open your browser
2. Go to: https://dashboard.render.com
3. Click on your PostgreSQL database (the one with the elephant icon 🐘)
4. Click the "Shell" tab at the top
5. Open the file: user_follows_migration.sql
6. Copy EVERYTHING from that file (Ctrl+A, Ctrl+C)
7. Paste into the Render Shell (Ctrl+V)
8. Press Enter

You should see:
  ✓ Table created
  ✓ Index on follower_id created
  ✓ Index on following_id created
  ✓ Index on created_at created
  ✓ User count columns added
  ✓ Count update function created
  ✓ Trigger created

  STEP 2: DEPLOY THE CODE
═══════════════════════════════════════════════════════════════════════

From PowerShell in the project root:

  git add .
  git commit -m "feat: implement followers/following system"
  git push origin main

This will trigger automatic redeployment on Render.
